About VisionGuard AI

Problem

Manual monitoring of classrooms, campuses, traffic areas and workplaces does not scale well. Important events can be missed when humans have to watch continuous video.

Solution

This system applies YOLO object detection, tracking, counting and alert rules to turn camera data into useful monitoring information.

Technology

Python, Ultralytics YOLO, OpenCV, FastAPI, WebSocket, JavaScript and SQLite.

Privacy

Camera frames can be processed locally. Raw webcam video is not stored by this application. Detection events are stored in SQLite. Users can delete the detection history.

Future scope

Custom-trained models, region-of-interest rules, email/SMS notifications, edge devices, multi-camera support and more advanced anomaly detection.
